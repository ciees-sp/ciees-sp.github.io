Lesson shape

Fixed blocks bookend every lesson. The middle is assembled from content blocks. Two chevron transitions sit at the fixed boundaries; slant transitions wrap interactive and video blocks wherever they land.

Block order

  • ①Introduction fixedhero image + intro text · tinted
  • ▼Chevron transition (points down)top boundary
  • ②In Practice fixed2-image gallery + heading · tinted
  • ···Content blocks, assembled as neededinteractive / scenario / content / MC / reflection
  • ▲Chevron transition (points up)bottom boundary
  • ③Lesson Takeaways fixedheading + summary · tinted

The tinted background bookends the lesson — Introduction, In Practice, and Takeaways all sit on a washed tint, so the learner feels the lesson open and close on the same plane. The middle moves through white and gray.

Block padding

Padding is how blocks group and breathe. Set it in the Format menu. Most blocks use M; reduce one side to join a block to its neighbor; set to zero to fuse blocks into one unit.

PaddingMeansUsed for
60 / 0 (M)60px top & bottom, 0 sidesStandalone block, full breathing room
60 / 0 / 3060 top, 30 bottomTop of a joined pair — reduced bottom meets the block below
30 / 0 / 6030 top, 60 bottomBottom of a joined pair — reduced top meets the block above
30 / 0 (S)30px top & bottomBlock joined on both sides
0No paddingFused stack — blocks read as one (overline + heading + interactive)

Throughout this guide, 60 / 0 means top/bottom 60, sides 0; a third number is the bottom when it differs from the top.

Backgrounds

Set the background in the Style panel (the palette icon on the block), under Color. Light and Gray are presets; the washed tints and dark come from Custom + a hex.

WantDo this
White bodyPick the Light preset
Gray bodyPick the Gray preset
Tint TealCustom → enter #DCEEF0 (or pick from Recently used)
Tint BlueCustom → enter #E0EAF0
Dark (video, v2)Custom → enter #16193E

Don't use "Theme tint." That's a different auto-generated color. The CPST washed tints only come from Custom + the exact hex above.

Gray rule
Standalone content is white by default. Switch a content block to gray when two white sections would otherwise sit back-to-back and blur together — gray gives one of them its own visual container without needing a transition.

Transition shapes

Two Mighty transition shapes carry the lesson's flow. Both are the Sharp style — the difference is the amplitude and where they're used.

ShapeUsed forSettings
Chevron The two fixed lesson boundaries: Introduction → In Practice (points down), and the block before Takeaways → Takeaways (points up). Sharp V. Frequency 3, Amplitude 50, padding 20/20. Direction follows bg-color order automatically.
Slant Brackets each Interactive and Video block — one slant in, one slant out, same direction. Shallow single slant. Frequency 2, Amplitude 20, padding 10/10. Consultant picks direction; vary it across the lesson.

Where no transition is used — Scenario boundaries and between standalone content groups — a Continue gate plus a background change carries the seam. Blocks meant to read as one unit share a background and run at 0 padding so there's no seam at all.

Continue gates

A Continue gate forces a pause and lets the next block come in on a fresh background. It also carries the seam where no transition is used.

Continue gate setup

Standalone content blocks

Body content between the interactive moments — paragraphs, numbered lists, grids. White by default; gray when two white groups would otherwise sit adjacent. Headings anchor groups; the padding ladder fuses a heading to the list or paragraph beneath it.

Understanding the Principles

    Key ethical principles include:
  • 1
    Autonomy: Respecting an individual's right to make their own choices.
  • 2
    Beneficence: Acting in the best interest of the individual you serve.
  • 3
    Confidentiality: Protecting an individual's private information.

These principles work together. Tension between them is normal.

Statement C overline — 4 steps
1. Choose Statement variant C · 2. Type "Interactive" (CSS auto-caps + pills it) · 3. Set all padding sliders to 0 · 4. Override the bg from gray (its default) to the section tint.

Overline + heading + Add code share the tint and run at 0 padding so they read as one composed unit. The two slants point the same way; pick a direction that differs from the previous interactive so the lesson doesn't repeat the same angle.
